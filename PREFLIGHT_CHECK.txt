## 🚀 Ready to Launch?

Si tous les ✅ sont cochés, vous êtes prêts!

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\run_campaign3.ps1
```

Le script va:
1. Générer le plan de 360 runs
2. Exécuter chaque run
3. Afficher la progression en direct
4. Créer les fichiers campaign3_plan_*.csv et campaign3_progress_*.csv
5. Générer logs dans resultsSA/ et resultTABU/

**Durée: 1-3 heures selon CPU et rapidité Tabu**

Une fois terminé:
```powershell
python analyze_campaign3.py
```

---

## ⚠️ En cas de problème

**Le script plante immédiatement?**
- Vérifier compilation: `javac --release 21 -d bin src/vrptw/*.java`
- Vérifier instances existent: `data/data101.vrp`, etc.

**Le script s'exécute mais très lent?**
- C'est normal pour Tabu! Laissez tourner (peut prendre plusieurs heures sur data1101)
- Ou réduire itérations: `.\run_campaign3.ps1 -Iterations "10000,30000"`

**Aucune erreur mais peu de fichiers générés?**
- Vérifier que `resultsSA/` et `resultTABU/` ont les bons droits d'accès en écriture
- Vérifier qu'il y a assez d'espace disque

**L'analyse Python échoue?**
- Vérifier que pandas est installé: `pip install pandas numpy`
- Vérifier que les logs ont bien été générés: `Get-ChildItem resultsSA/Exp*/executions_log.csv`
