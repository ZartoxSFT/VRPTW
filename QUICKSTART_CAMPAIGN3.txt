## 3 étapes pour démarrer

### Étape 1️⃣ : Compiler (si pas déjà fait)

```powershell
javac --release 21 -d bin src/vrptw/*.java
```

**Vérifier:**
```powershell
Test-Path "bin/vrptw/Main.class"  # Doit retourner True
```

### Étape 2️⃣ : Lancer la Campagne 3

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\run_campaign3.ps1
```

**C'est tout!** Le script va:
- ✅ Générer le plan de 360 runs
- ✅ Exécuter les runs un par un
- ✅ Afficher la progression
- ✅ Créer les fichiers `campaign3_plan_*.csv` et `campaign3_progress_*.csv`
- ✅ Générer tous les logs dans `resultsSA/` et `resultTABU/`

**Durée:** 1-3 heures selon votre CPU

### Étape 3️⃣ : Analyser les résultats

Une fois la campagne terminée:

```powershell
python analyze_campaign3.py
```

Génère automatiquement:
- `campaign3_consolidated_*.csv` - Tous les résultats fusionnés
- `campaign3_summary_*.csv` - Statistiques (moyennes, écart-types, min/max)
- `campaign3_feasibility_*.csv` - Taux faisabilité
- `campaign3_runtime_*.csv` - Temps d'exécution
- `campaign3_comparison_sa_tabu_*.csv` - Comparaison directe

---

## Qu'est-ce qu'on teste exactement?

```
360 runs =

  3 instances (data101, data111, data1101)
  × 10 seeds (robustesse stats: 41..50)
  × 2 modes TW (sans, avec)
  × 2 algos (SA, Tabu)
  × 3 itérations (10k, 30k, 100k)
  
  = 3 × 10 × 2 × 2 × 3 = 360
```

### Paramètres fixes

- **SA**: T=1250, cooling=0.9993 (meilleur trouvé campagnes 1-2)
- **Tabu**: tenure=40 (meilleur trouvé)
- **Voisinage**: inter-relocate (éprouvé)

## ⚠️ Pièges communs

### ❌ "Le script ne compile pas"

```
ERROR: Cannot find compiled classes in 'bin'.
```

→ Exécuter d'abord:
```powershell
javac --release 21 -d bin src/vrptw/*.java
```

### ❌ "Tabu est TRÈS lent sur data1101"

C'est normal! 1100+ clients = exploration énorme. Laissez tourner (possibilité: réduire à 30k itérations pour Tabu sur data1101).

### ❌ "Python ne trouve pas les logs"

```
ERROR: No execution logs found.
```

→ Vérifier que les runs ont bien généré files:
```powershell
Get-ChildItem resultsSA/Exp*/executions_log.csv | Measure-Object
Get-ChildItem resultTABU/Exp*/executions_log.csv | Measure-Object
```

Doit être > 0.
